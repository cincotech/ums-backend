# ums-backend
The UMS Backend is the server-side component of the University Management System (UMS) — a modular platform designed to digitalize and automate all academic, administrative, and financial activities within a university. It is built with Django REST Framework

## API Endpoints - Dashboard Collection Agent

### Base URL: `/dashboard/finance/`

- `/dashboard/finance/banks/` - Gestion des banques
- `/dashboard/finance/wordings/` - Gestion des libellés
- `/dashboard/finance/fees-sheets/` - Gestion des feuilles de frais
- `/dashboard/finance/payment-installements/` - Gestion des échéanciers de paiement
- `/dashboard/finance/payment-reminders/` - Gestion des rappels de paiement
- `/dashboard/finance/payment-plans/` - Gestion des plans de paiement
- `/dashboard/finance/payment-promises/` - Gestion des promesses de paiement
- `/dashboard/finance/payments/` - Gestion des paiements
- `/dashboard/finance/collection-correspondence/` - Gestion de la correspondance de recouvrement
